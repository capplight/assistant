# ТЗ v1.1 — точка входа

**Статус:** ТЗ v1.1 от 2026-11-05 (v1.0 — от того же дня, до решений о страницах), «заморожено» для Core MVP. Открытые вопросы — в [FOUNDER-DECISIONS.md](FOUNDER-DECISIONS.md).
**Как сделано:** 4 автора (продукт, дизайн, инженерия, бизнес-право) написали черновики → перекрёстное ревью → редакция свела расхождения в решения R-01…R-45 ([02-resolutions.md](02-resolutions.md)) → предложения о строке помощника и страницах → решения R-46…R-60 и ответы основателя на Ф-21…Ф-24 ([03-persistent-chat-decisions.md](03-persistent-chat-decisions.md)) → авторы обновили финальные части → проверка согласованности (отчёт ниже). Решения основателя №1–10 из [00-brief.md](00-brief.md) и ответы на Ф-21…Ф-24 не менялись; где команда против — вопрос вынесен в Ф-N.

## Продукт в 6 предложениях
1. Универсальный помощник в телефоне — работает как ChatGPT или Claude, но проще и понятнее, для тех, кто ими не пользуется (в том числе старшее поколение).
2. «Как Notion AI, который сам всё организует» — только в телефоне и над всеми записями человека: голос, «Поделиться», фото, файлы, Telegram.
3. Человек сам выбирает **страницы** из 6 простых шаблонов (Заметки, Дела и напоминания, Покупки, Документы и КП, **Расходы**, Своя страница), плюс всегда есть «Сегодня»; страница — это вид на общую память, а не папка: раскладывает агент, а человек может сам переставить и перенести любую запись.
4. Внизу каждой страницы — одна **строка помощника** («Скажите или напишите…»): результат сразу на странице с «Отменить», текстовый ответ — плашкой «Открыть ответ», полная Переписка — по кнопке; агент запоминает, убирает повторы, напоминает как будильник, находит с источником, делает КП и считает траты (итоги — только кодом).
5. Наружу ничего не уходит без «Да», всё внутреннее можно отменить; данные хранятся в Казахстане.
6. Казахстан (+ Кыргызстан) — только стартовый рынок: русский и казахский, бренд и дизайн универсальные, без национальных мотивов.

Публичная фраза: «Скажите — я запомню, напомню и найду» (финал — с названием, Ф-8/Ф-9).

## Что входит в MVP
Основатель решил: «сроки неважны, не торопимся, делаем всё» (Ф-22) — ничего не переносим в Full ради скорости.

**Core — 21–23 недели** (ядро для семьи и первых незнакомых; план — [3-engineering, 11](final/3-engineering.md)):
- Захват: «Поделиться» F-01, голос F-02 (без живой расшифровки), фото F-03, файлы F-04; память как текст и правило оригиналов F-05; источник на карточке F-06.
- **Страницы и строка помощника:** строка на каждой странице + одна Переписка F-37; страницы из 6 шаблонов, выбор, «Мои страницы» F-38 (≤20 страниц); перестановка агентом F-39; ручная перестановка и перенос F-41 (офлайн, «человек главнее ИИ»); правка шаблона F-42 (≤5 своих полей); навигация «Сегодня» + до 3 страниц + «Ещё».
- **«Расходы» F-40** (нед. 12–13): голос/текст, форма, фото чека, «Поделиться» квитанцией и выпиской PDF, итоги кодом по валютам.
- Поиск F-07 (в строке и «Найти на странице»); вопросы с источниками + «Сообщить о проблеме» F-08; стопки как группы внутри страниц F-09; Повторы F-10 (уборка — нед. 10).
- Напоминания-будильники F-11 (нед. 8); дела и списки F-12.
- КП из ТЗ F-13 (PDF; DOCX — нед. 15), профиль компании F-14, «Мой прайс» F-34, черновики F-15.
- «Сегодня» F-16; «Что я сделал» и Отмена F-17; подсказки и предложения страниц F-18; **первый запуск «как в Excel»** F-19 (знакомство + три пути); согласие F-20; аноним + SMS F-21; RU/KK F-22.
- Импорт Telegram из файла F-23 (нед. 10); почта через «Поделиться» F-25; экспорт F-26; удаление аккаунта F-27 (веб — нед. 16); автономия F-28; привычки F-29 (учатся и на ручных переносах); офлайн F-30.
- Внутреннее: учёт ошибок и стоимости ИИ F-31, лимиты F-32 (с первого дня), аналитика `events` в КЗ F-35.

**Full / публичный релиз — 29–33 недели от старта:** пересылка боту F-24 и вход в Telegram по коду (F-23, по Ф-4) — нед. 24–25; третий LLM — нед. 26; сводка стопки (P1) и «Настраиваю для другого человека» F-36 — нед. 27; личный адрес пересылки почты (F-25, P2) — нед. 28; доработка KK-голоса — нед. 29; релиз Android, затем iOS — нед. 30–31; буфер — нед. 32–33.

**После MVP:** семейный доступ F-33 (первым), формулы / связи / свои итоги / доска / календарь и шаблоны от агента, push банков и Open Banking, прямая отправка из Gmail, импорт WhatsApp, Kaspi/1С, тарифы, Apple/Google-вход, Узбекистан.

## Что изменилось в v1.1
- **Страницы вместо трёх вкладок:** 6 шаблонов + «Сегодня», страница = вид (R-46…R-51, R-57); ручная перестановка везде (R-54).
- **Строка помощника** на каждой странице и одна Переписка (R-52, R-53, R-56); новые F-37…F-42, US-23…US-33, S34…S42.
- **«Расходы» в первой версии** полноценным шаблоном (Ф-21, R-59), с выписками PDF и итогами кодом.
- **Первый запуск «как в Excel»:** знакомство S01–S02 → согласие → S41 три пути, по умолчанию «сначала фраза» (Ф-24, R-60); US-14 переформулирован (≤90 с от запуска / ≤45 с от S41).
- **Сроки:** Core 11–13 → **21–23 нед.**, Full 16–22 → **29–33 нед.**; волны сдвинуты; сроки решений основателя пересчитаны (Ф-1 — нед. 8, поля КП и НДС — нед. 14, название — нед. 8, крайний 16).
- **Бизнес:** новые конкуренты (Kaspi, банки, учёт трат), правовые пункты о финансовых данных и Переписке; бюджет беты не меняется, разработка до релиза дороже.

## Приложение. Решения команды (R-01…R-60)
- **R-01** Согласие: до ZDR — «не обучаются; хранят ≤N дней», «не хранят» — только после ZDR.
- **R-02** В согласии сразу все провайдеры; новый — только новой версией.
- **R-03** Анонимный аккаунт с первого запуска; S05 до первой фразы; номер — после первого результата.
- **R-04** S05: два пункта (обработка в КЗ / передача за рубеж), 18+ и Условия, «Согласен» / «Без ИИ».
- **R-05** «Без ИИ»: только клавиатура; напоминания из фраз — при Ф-1, иначе ручная форма.
- **R-06** «ИИ»: нет в рекламе и кнопках; есть в раскрытиях; одна метка на созданном контенте.
- **R-07** Удаление аккаунта: один путь, блок сразу, 7 дн. отмены, ≤24 ч, бэкапы ≤30 дн.
- **R-08** Аноним 90 дн. без активности → удаление; любой аккаунт 24 мес. → предупреждение → удаление.
- **R-09** Повторы будильника ставит телефон; сервер шлёт push при отсутствии `fired_local` 3 мин.
- **R-10** Экран будильника по платформам: FSI / heads-up / AlarmKit / time-sensitive.
- **R-11** Кнопки «Сделано» / «Отложить на 10 минут»; 2 уровня: Будильник и Уведомление.
- **R-12** S04 — только уведомления; S15 (точные будильники, FSI, автозапуск) после S04b.
- **R-13** Звенит на последнем активном телефоне; тихие часы 22:00–08:00.
- **R-14** Push по умолчанию без содержимого; данные о здоровье — никогда.
- **R-15** WhatsApp: файл через «Поделиться», чат выбирает человек; текст — `wa.me`.
- **R-16** Контакт — системный выбор одного, без разрешения и без загрузки.
- **R-17** Живой расшифровки нет; текст через 1–3 с после «Готово».
- **R-18** Бюджет: класс `documents` отдельно; незаконченное КП не обрывать.
- **R-19** Лимиты — P0 с первого дня; семья без лимита + алерт.
- **R-20** Запасной провайдер: доля от основного + аварийный лимит; сбой — алерт, не тихое отключение.
- **R-21** Постоянные расходы $250–320 + разработка $100–200/мес; VM-2 при ~1 000 активных.
- **R-22** Оплаты в приложении нет; тест — вне приложения, счётом (Ф-7).
- **R-23** Golden set и CI вне КЗ — только обезличенное; голоса — с письменным согласием.
- **R-24** Маскировка ИИН/БИН, IBAN, карт во всех задачах ИИ.
- **R-25** Новые данные и API: привычки, подсказки, повторы, стопки, версии КП.
- **R-26** Вход: аноним + SMS, +7/+996; Apple/Google — после MVP.
- **R-27** DOCX по запросу — в Core (с v1.1 — нед. 15).
- **R-28** Telegram: файл — Core (с v1.1 — нед. 10); бот и вход по коду — Full (с v1.1 — нед. 24–25) (Ф-4).
- **R-29** Новая F-34 «Мой прайс»; цена: прайс → прошлые КП → «укажите цену».
- **R-30** Правка КП фразой применяется сразу с подсветкой и «Отменить».
- **R-31** Автономия по умолчанию «Спрашивать» с исключениями; через 7 дн. — «Делать мелочи сам» (Ф-3).
- **R-32** Точный повтор склеивается сам с «Отменить»; похожий — «Объединить?».
- **R-33** Окно «Отменить» и корзина записей — 30 дней.
- **R-34** Оригиналы удаляются по правилу, принятому один раз; логотип, подпись, печать — всегда.
- **R-35** Подсказки: ≤2/день 14 дн., далее ≤1; 2× «Не сейчас» → пауза 30 дн.
- **R-36** «Проверьте» всегда: телефон, сумма, ИИН/БИН, IBAN, номер документа.
- **R-37** Онбординг без анкеты; первая подсказка — «Напомни в пятницу оплатить свет».
- **R-38** Магазины КЗ + КГ; РФ — нет; номера не блокируем.
- **R-39** Казахский: экран готов только с вычитанными KK-строками; KK-голос — метка «бета».
- **R-40** Аналитика — свой журнал `events` в КЗ, без содержимого.
- **R-41** «Сообщить о проблеме» в ответе и КП.
- **R-42** Волны по готовности функций; следующий — если предыдущий пользовался неделю.
- **R-43** Мелочи: Share — только текст, без прогнозов о здоровье и др.
- **R-44** Семейный доступ — после MVP, первым; в MVP — резерв поля «Кому».
- **R-45** Публичная фраза: «Скажите — я запомню, напомню и найду».
- **R-46** Страница — вид на общую память, не папка; запись может быть на нескольких страницах (Ф-23).
- **R-47** Слова: «Страница», «Мои страницы», «Переписка», строка «Скажите или напишите…»; «чат», «шаблон», «ИИ» в кнопках нет.
- **R-48** Выбор страниц после первой пользы: 2–3 отмечены, «Подходит», пропуск = набор по умолчанию.
- **R-49** «Сегодня» — системная страница: всегда первая, убрать нельзя, в каталог не входит.
- **R-50** Каталог: 6 рабочих шаблонов (Заметки, Дела и напоминания, Покупки, Документы и КП, Расходы, Своя страница); ≤20 страниц.
- **R-51** Правка шаблона: имя, иконка, показать/скрыть (кроме ★), порядок, ≤5 своих полей 5 типов, вид, сортировка; «Вернуть как было».
- **R-52** Строка помощника на каждой странице: действие — результат на странице + «Отменить»; текст — плашка «Открыть ответ»; одна Переписка.
- **R-53** Действия — над текущей страницей; вопросы — по всем страницам с источником; «это / здесь» — переспрос.
- **R-54** Ручная перестановка везде (жест + кнопка «⋯»), офлайн; человек главнее ИИ; убранное вручную агент не возвращает.
- **R-55** Новую страницу агент создаёт только по просьбе или после «Да»; предложение ≤1 в неделю, не в первые 10 мин.
- **R-56** Контекст ≤12 тыс. токенов по слоям, ≤4 шагов инструментов, изменения — только при намерении человека, свёртка без `untrusted_data`.
- **R-57** Навигация: «Сегодня» + до 3 страниц + «Ещё» (при шрифте ≥150% — + 2); вкладки «Найти» нет.
- **R-58** Сроки: вариант «Всё сразу» (Ф-22) — Core 21–23 нед., Full 29–33 (план инженерии).
- **R-59** «Расходы»: итоги считает код, по валютам отдельно; Kaspi и банк — только через «Поделиться»; сумма — «Проверьте».
- **R-60** Первый запуск: знакомство S01–S02 (≤30 с, «Пропустить») → S05 → S41 три пути; по умолчанию — «сначала фраза».

## Глоссарий простыми словами
- **Страница** — вид на записи по шаблону (например, «Расходы»); запись живёт в общей памяти и может быть на нескольких страницах.
- **Шаблон** — заготовка страницы: какие поля и какой вид.
- **MVP** — первая рабочая версия, чтобы проверить идею на людях; **Core** — ядро для семьи, **Full** — для магазинов.
- **API** — «розетка», через которую программы обмениваются данными.
- **Провайдер ИИ** — компания, чей ИИ мы вызываем за деньги: Anthropic, OpenAI, Google, Groq.
- **STT / OCR** — превращение речи в текст / распознавание текста на фото и сканах.
- **ZDR** — «нулевое хранение»: провайдер не сохраняет наши запросы.
- **Consent gate** — проверка в коде: без согласия данные к ИИ не уходят.
- **AlarmKit** — механизм iPhone (iOS 26+) для настоящих будильников приложений.
- **FSI** — полноэкранное уведомление Android поверх блокировки.
- **Embeddings** — числовой «отпечаток смысла» текста для поиска по смыслу.
- **RRF** — способ свести поиск по словам и по смыслу в один список.
- **Golden set** — 150 эталонных примеров для проверки качества ИИ.
- **Bake-off** — сравнение провайдеров на одних и тех же примерах.
- **D-U-N-S** — номер компании, без которого Apple не откроет аккаунт организации.
- **94-V / 230-VIII** — законы РК о персональных данных и об искусственном интеллекте.
- **P0 / P1 / P2** — без этого не выпускаем / входит, но можно начать без него / желательно.
