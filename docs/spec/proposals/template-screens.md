## Коротко для основателя

Каждая страница становится своим инструментом. «Заметки» — это стена из цветных стикеров: по умолчанию ровными рядами, а по желанию — свободная доска, где стикер ставится куда угодно. «Расходы» — калькулятор трат: большой итог как на табло, крупные цифровые кнопки и лента, похожая на чек. «Дела и напоминания» — ежедневник с часами. «Покупки» — список на холодильник с режимом «В магазине». «Документы и КП» — картотека с папками по клиентам и полосой статуса КП. «Своя страница» — тетрадь, которую вы сами расчерчиваете списком, чек-листом или таблицей. «Сегодня» — отрывной листок дня. Одинаковыми остаются рамка страницы (заголовок, «Найти на странице», «Порядок», «Настроить»), строка помощника внизу, плашка ответа, «Отменить», карточка записи и меню «⋯ Ещё». Поэтому человек, который научился работать с одной страницей, справится и с остальными. Помощник по вашей просьбе может менять вид любой страницы: раскладку, режим, цвета, видимые поля и группы. Каждое такое изменение показывается в «Что изменилось» и отменяется одной кнопкой. То, что вы поставили руками, помощник трогает только после вашего «Да» (раздел 2.8). Данные почти не меняются: записи по-прежнему лежат в одной общей памяти, добавляются цвет и место стикера, запись вычислений в трате, ваш порядок категорий и пометка «кто это настроил». Категорий трат 8. В настройках каждой страницы есть запасной вид «Простой список». Цена решения — **+5–7 недель** к ядру: Core займёт **26–30 недель** вместо 21–23, Full — **34–40** вместо 29–33. Вы это приняли (Ф-29).

## 1. Моё мнение (честно)

**С чем согласен.** Сейчас S37 — один список с разными заголовками, и разница между «Заметками» и «Покупками» видна только по словам. Инструмент, который выглядит как знакомая вещь (стикер, чек, ежедневник), понятен людям 45+ без объяснений. Это сильнее, чем текст «что здесь будет», и прямо работает на решение №9 («интересный UI с очевидными преимуществами»).

**Чего это стоит:**
1. **Удобство.** Семь разных экранов — значит семь разных привычек. Пожилому человеку легко потеряться, если на каждой странице кнопки стоят по-разному. Как снимаем риск: общая рамка и общие элементы (раздел 3) стоят на одних и тех же местах. Различается только середина страницы.
2. **Единый стиль.** «Бумага и чернила» выдерживает такие экраны: стикер, чек и картотека сделаны из бумаги. Нельзя только раскрашивать каждую страницу в свой яркий цвет. Цвет остаётся у стикеров, остальное — бумага и чернила.
3. **Сроки.** Получается +5–7 недель (раздел 6). Из них 1,5–2 недели — свободная доска, ещё около недели — переделка «Дел» и «Покупок», уже собранных на неделе 9.
4. **Доступность.** Свободная доска, широкая таблица и плотная клавиатура при шрифте 200% ломаются первыми. Поэтому у каждого экрана расписан свой вид для 200%, при крупном шрифте доска показывается рядами, а в настройках есть запасной «Простой список» (Ф-30).
5. **Помощник меняет вид (Ф-31).** Это сильная возможность («сделай Покупки по магазинам», «покажи таблицей»), но для 45+ есть риск: страница вдруг выглядит иначе. Поэтому помощник меняет вид только по просьбе или после «Да», всегда с «Что изменилось» и «Отменить» (раздел 2.8).

Решения основателя не менял: свободная доска, изменения вида помощником и все сроки внесены так, как он сказал.

## 2. Экраны по шаблонам

Общая схема для всех экранов: **рамка** (заголовок, «Найти», «Порядок», «Настроить») → **инструмент** (своё для шаблона) → строка помощника → вкладки. В макетах рамка показана коротко.

Ниже «Без ИИ» = режим без согласия на ИИ (R-05): микрофона нет, вместо него кнопка «Написать». Короткие фразы на телефоне разбирают простые правила в коде («5000 бензин», «молоко, хлеб»), но только если основатель примет Ф-1 «сначала код». Иначе остаётся ручная форма. Ручные действия (галочка, перестановка, перенос, цвет, ввод с клавиатуры) работают без сети сразу и без исключений (F-30).

### 2.1 Заметки — стена стикеров

**Зачем.** Записать мысль и сразу увидеть всё записанное, как листки на холодильнике или мониторе. Стопки (F-09) становятся пачками стикеров.

```
┌──────────────────────────────┐
│ ≡ Заметки  [Порядок][Настроить]│ рамка
│ 🔍 Найти на странице          │
│ ПАЧКИ                         │
│ ┌────────────┐┌────────────┐  │ пачка = 2 листа под низом
│ │Ремонт   14 ││Мастера   6 │  │ цвет пачки = цвет верхнего
│ │плитка 24м²,││Ерлан, Сер- │  │ 2 строки предпросмотра
│ │грунтовка…  ││гей-сантех… │  │
│ └┴──────────┘┘└┴──────────┘┘  │
│ [Рецепты 9] [Дача 5] [Ещё 2 ›]│ чипы, как сейчас
│ СТИКЕРЫ                       │
│ ┌────────────┐┌────────────┐  │ 2 колонки, ровные ряды
│ │📌          ││Купить      │  │ 📌 = приколото наверх
│ │Код домофона││грунтовку   │  │ title2 по первой строке
│ │4512        ││2 банки     │  │ body
│ │сегодня  ⋯ ││(🎤) вчера ⋯│  │ meta + [⋯ Ещё] 48
│ └────────────┘└────────────┘  │
│ ┌────────────┐┌────────────┐  │ жёлтый / розовый / зелёный /
│ │…           ││…           │  │ голубой / персиковый / белый
│ └────────────┘└────────────┘  │
│ [+] [Про: Заметки ▾ · Скаж…](🎤)│ строка помощника
├──────────────────────────────┤
│Сегодня│Заметки│ Дела │ … │Ещё │
└──────────────────────────────┘
```

- **Стикер:** квадрат, примерно 160×160 pt, `radius.note` = 4, лёгкий «загиб» правого нижнего угла (декор). Текст — до 5 строк, дальше «…». Без поворотов: наклонный текст хуже читается.
- **Два режима (Ф-28):** переключатель под «Найти»: `[●Ряды | Доска]` (48 pt; он же есть в S38 → «Вид»). По умолчанию «Ряды».
- **Ключевые действия.** Нажать на стикер — открыть S09. «⋯ Ещё» даёт общее меню и сверху два своих пункта: «Цвет» (6 кружков 48 pt с подписями «Жёлтый»…) и «Приколоть наверх / Открепить». Голосом: «сделай жёлтой», «приколи код домофона», «раскрась по темам» (раздел 2.8). «Разложи заметки» собирает стикеры в пачки с анимацией `motion.stack`, как сейчас.

**Режим «Доска»** — стикеры лежат там, куда их поставили пальцем.

```
┌──────────────────────────────┐
│ ≡ Заметки  [Порядок][Настроить]│
│ [ Ряды | ●Доска ]             │
│ ┌──────────┐                  │ доска шириной экрана,
│ │Код домо- │      ┌──────────┐│ растёт вниз; горизонтальной
│ │фона 4512 │      │Купить    ││ прокрутки нет
│ └──────────┘      │грунтовку ││ стикер 140×140, без наклона
│        ┌──────────┤2 банки   ││ можно положить внахлёст
│        │Ремонт 14 └──────────┘│ пачка тоже лежит, где положили
│        │(пачка)   │           │
│        └┴─────────┘┘          │
│ [+] [Про: Заметки ▾ · Скаж…](🎤)│
└──────────────────────────────┘
```

- Перетащить — долгое нажатие 400 мс, отпустить где угодно. Стикер прилипает к невидимой сетке 8 pt. Взятый стикер поднимается наверх стопки внахлёст.
- **Без жестов:** «⋯ Ещё → Подвинуть» показывает 4 большие стрелки «Выше · Ниже · Левее · Правее», каждая сдвигает на полстикера, шторка не закрывается. Есть ещё «Положить наверх доски».
- **Первое включение доски:** стикеры раскладываются сеткой в порядке рядов, ничего не теряется. Обратно в «Ряды»: порядок рядов прежний, места на доске запоминаются на следующий раз.
- **Новый стикер** ложится в первое свободное место сверху и подсвечивается 600 мс.
- **Чтение с экрана** идёт сверху вниз, слева направо по месту на доске и объявляет «Стикер 3 из 12».
- **Шрифт ≥150%:** доска показывается рядами в порядке «сверху вниз, слева направо» с плашкой «При крупном шрифте доска показана рядами. Места стикеров сохранены». Двигать можно стрелками «Выше / Ниже», места на доске при этом пересчитываются.
- **Ручное и помощник:** на доске каждое место, куда человек поставил стикер сам, считается ручным. «Разложи заметки» на доске спрашивает: «Вы сами расставили 9 стикеров. Переставить и их? [Да] [Оставить мои]».
- **Пусто:** один бледный стикер-пример с надписью «Здесь будут ваши заметки. Скажите: «Запиши код домофона 4512»» и 2–3 примера над строкой.
- **Строка помощника.** Записать («запиши…»), разложить, перекрасить, приколоть, найти («где код домофона?» — плашка ответа с источником). Подсказка: «Например: запиши размер окна 120 на 80».
- **Ручной порядок.** В «Рядах» стикеры идут слева направо, сверху вниз. Это тот же порядок `position` (LexoRank), что и сейчас: перетащить стикер или нажать «Выше / Ниже» значит сдвинуть его на одно место. Приколотые всегда идут первыми. Цвет, который человек поставил сам, и «приколоть» помощник без «Да» не меняет (R-54, раздел 2.8). Цвет, который поставил помощник, он может менять по просьбе.
- **Без ИИ / офлайн:** всё, кроме «разложи», «раскрась по темам» и поиска по смыслу. Цвет, «приколоть», порядок, доска и запись с клавиатуры работают сразу.
- **200%:** одна колонка, стикер во всю ширину, высота по тексту. Пачки идут списком. Цвет остаётся полосой 8 pt слева, плюс фон (иначе страница превращается в радугу).

### 2.2 Расходы — калькулятор трат

**Зачем.** Быстро записать трату и сразу увидеть, сколько ушло. Всё считает код (R-59). Экран заменяет S40 и сохраняет все его правила.

```
┌──────────────────────────────┐
│ ▣ Расходы  [Порядок][Настроить]│
│ [Неделя|●Месяц|Год|Период…]   │ сегменты 48
│ ┌──────────────────────────┐  │ «табло», surface, рамка
│ │ ‹   Ноябрь 2026       ›  │  │
│ │              214 600 ₸   │  │ type.amount 48/56, справа,
│ │ 23 траты · ⚠ 2 проверить │  │ табличные цифры
│ │ Отдельно: 120 $          │  │ другая валюта — строкой
│ └──────────────────────────┘  │
│ ┌──────────────────────────┐  │ ВВОД (свёрнут — одна кнопка
│ │           1 200 + 350 ₸  │  │  «Ввести трату» 56)
│ │ = 1 550 ₸                │  │ код считает выражение
│ │ [Продукты][Дом и ремонт] │  │ все 8 категорий — чипы 48,
│ │ [Транспорт][Здоровье]    │  │ в порядке человека
│ │ [Дети и семья][Кафе и под│  │
│ │ арки][Коммуналка и связь]│  │
│ │ [Другое]                 │  │
│ │ ┌───┬───┬───┬───┐        │  │ клавиши 64
│ │ │ 7 │ 8 │ 9 │ ⌫ │        │  │
│ │ │ 4 │ 5 │ 6 │ + │        │  │
│ │ │ 1 │ 2 │ 3 │ − │        │  │
│ │ │ 000 │ 0 │ ,│Записать│  │  │ accent
│ │ └───┴───┴───┴───┘        │  │
│ └──────────────────────────┘  │
│ ПО КАТЕГОРИЯМ                 │ полосы + число (как S40)
│ Дом и ремонт ██████ 186 400 ₸ │
│ ЛЕНТА · как чек               │
│ ┄┄┄┄┄┄┄┄ Сегодня ┄┄┄┄┄┄┄┄┄┄   │ пунктир — «чековая» лента
│ Бензин · Транспорт   5 000 ₸ ⋯│ сумма справа, табличная
│ Плитка · Дом  ▓48 500 ₸▓ ⚠   ⋯│ «проверьте» (R-36)
│ ┄┄┄┄┄┄┄┄ Итого за день 53 500 │
│ [+] [Про: Расходы ▾ · Потрат…](🎤)│
└──────────────────────────────┘
```

- **Ключевые действия.** Сначала сумма (клавиши 64 pt, как в S28), потом категория и «Записать»: трата вносится за ≤3 нажатия после суммы (US-31). Кнопки «+ / −» складывают несколько чеков в одну трату («1 200 + 350»). Выражение считает код (`Decimal`), без ИИ. Дата — чип «Сегодня ▾» над клавишами (Сегодня / Вчера / Другая). После «Записать» итог на табло пересчитывается (`motion.count`), новая строка ложится в ленту с подсветкой 600 мс, в строке помощника появляется «Записал 1 550 ₸ · Продукты [Отменить]».
- **Клавиши свёрнуты по умолчанию**, если трат больше 10. Тогда видна одна кнопка «Ввести трату», чтобы табло и лента не уезжали за экран. При первом открытии и на пустой странице клавиши раскрыты.
- **Категории — 8 (решено, раздел 4).** Продукты · Дом и ремонт · Транспорт · Здоровье · Дети и семья · Кафе и подарки · Коммуналка и связь · Другое. Все 8 видны чипами сразу, слоя «Ещё» нет. Свои категории (из S38) встают после восьми; если категорий больше 10, лишние уходят под «Ещё ›». Пока человек не трогал порядок, чипы идут по частоте. После первой ручной перестановки (S38: ↑ ↓) порядок его, и помощник меняет его только с «Да».
- **Пусто:** табло «0 ₸ · Пока трат нет», клавиши раскрыты, подсказка «Наберите сумму или скажите: «потратил 5000 на бензин»». Есть ссылка «Как принести выписку Kaspi ›»: она открывает шторку из 3 шагов «Поделиться».
- **Строка помощника.** «потратил 5000 на бензин» попадает в ленту (сумма с «Проверьте», если сказана голосом). Вопрос «сколько на лекарства с сентября?» даёт плашку ответа: цифру считает код, источник — «▣ Расходы · 4 траты». Можно «перенеси плитку в Дом». Фото чека и выписка приходят через «+» и «Поделиться», как в S40.
- **Ручной порядок.** Лента идёт по датам: внутри дня человек может переставить строки, но перенести трату на другой день нельзя, для этого меняют дату. Порядок категорий принадлежит человеку.
- **Без ИИ / офлайн:** клавиши, итоги (TS-порт `calc`, неделя 12), лента и категории работают полностью. Фразу «5000 бензин» разбирает правило (при Ф-1). Чек и выписка ждут сети с меткой «Ждёт связи».
- **200%:** табло — `type.amount` с ограничением 1,6× (иначе число не помещается), всё остальное масштабируется на 2×. Клавиши остаются сеткой 4×4: они и так 64 pt. Подписи на клавишах масштабируются до 1,5×, чтобы цифры не вылезали. Чипы категорий — список в 1 колонку. Ввод открывается на весь экран, а табло и лента идут ниже прокруткой.

### 2.3 Дела и напоминания — ежедневник

**Зачем.** Увидеть день по часам и ничего не пропустить. Будильники (F-11) и дела (F-12) лежат на одном листе.

```
┌──────────────────────────────┐
│ ☑ Дела     [Порядок][Настроить]│
│ [●Сегодня | Скоро | Пропущено 1]│ сегменты, как сейчас
│ Вторник, 10 ноября            │ title2
│ ┌──────────────────────────┐  │ «лист ежедневника»
│ │08:00 ─ ☐ Таблетка маме    │  │ колонка времени 64 pt
│ │      🔔 Будильник         │  │ колокол + слово
│ │10:00 ─ ☐ Позвонить Ерлану │  │
│ │ сейчас ━━━━━━━━━━━━━━━━━━ │  │ линия «сейчас» accent
│ │18:00 ─ ☐ Забрать Алину    │  │
│ │      Уведомление          │  │
│ ├ ─ ─ ─ БЕЗ ВРЕМЕНИ ─ ─ ─ ─┤  │
│ │ ☐ Оплатить свет      ⋯   │  │ ручной порядок здесь
│ │ ☐ Записаться к врачу ⋯   │  │
│ ├ ─ ─ ─ СДЕЛАНО (2) ─ ─ ─ ─┤  │ серым, «Вернуть»
│ └──────────────────────────┘  │
│ [+ Новое напоминание]          │ outline 56
│ [+] [Про: Дела ▾ · Скажите…](🎤)│

«Скоро» — тот же лист по дням: заголовки «Завтра, среда» / «Пт, 13 ноя».
«Пропущено» — красные строки [Сделано] [Перенести] (как сейчас).
```

- **Ключевые действия.** Галочка 40 pt (сейчас 32; для 45+ лучше больше). Нажатие на строку открывает S13. «⋯ Ещё» даёт общее меню и сверху «Перенести время» (+15 мин / +1 час / Завтра / Выбрать). Сделанное уходит вниз серым, пункт «Вернуть» остаётся.
- **Пусто:** пустой лист с часами 9 / 12 / 18 бледным цветом и надписью «На сегодня ничего. Скажите: «Напомни завтра в 7 выпить таблетку»».
- **Строка помощника.** Поставить напоминание (результат ложится на лист в свой час и подсвечивается), отметить («отметь таблетку»), перенести («перенеси звонок на 11» — это изменение существующего напоминания, поэтому S25 с «Да», R-31), спросить («что у меня в пятницу?»).
- **Ручной порядок.** У дел со временем порядок задаёт время: перетащить такую строку нельзя, вместо «Выше / Ниже» в её меню стоит «Перенести время». Это правило, а не потеря: двигать 10:00 под 18:00 бессмысленно. Дела без времени человек расставляет как хочет. Это новое уточнение к R-54, его надо записать в 2-design §4.7.
- **Без ИИ / офлайн:** лист, галочки, ручная форма S13 и будильники работают (они стоят на телефоне, R-09). Фразы разбираются правилами при Ф-1.
- **200%:** колонка времени уходит над делом строкой («10:00 · Будильник» — `type.bodyStrong`), дело идёт ниже во всю ширину. Линия «сейчас» становится подписью «Сейчас 11:20».

### 2.4 Покупки — список на холодильник

**Зачем.** Собрать список дома и пройти по нему в магазине одной рукой.

```
┌──────────────────────────────┐
│ ⊡ Покупки [Порядок][Настроить]│
│ Осталось 5 из 8               │ title2 + полоса прогресса
│ ┌──────────────────────────┐  │ «листок в клетку»
│ │ МАГНУМ                   │  │ группа = «где купить»
│ │ ☐ Молоко        [− 2 +] ⋯│  │ количество кнопками 48
│ │ ☐ Хлеб                  ⋯│  │
│ │ АПТЕКА                   │  │
│ │ ☐ Цитрамон              ⋯│  │
│ │ КУПЛЕНО (3)  [Убрать все]│  │ зачёркнуто, серым, «Вернуть»
│ │ ☑ ~~Яйца~~      [Вернуть]│  │
│ └──────────────────────────┘  │
│ [  🛒 Я в магазине  ]         │ accent 56 — режим
│ [+] [Про: Покупки ▾ · Купить…](🎤)│
└──────────────────────────────┘
Режим «В магазине» (та же страница, другой вид):
│ ‹ Выйти      Осталось 5      │
│ ☐  МОЛОКО  ×2                │ type.title1, строка 72 pt
│ ☐  ХЛЕБ                      │ нажать по всей строке = куплено
│ ☐  ЦИТРАМОН                  │ экран не гаснет
│ [Про: Покупки] (🎤)           │ строка свёрнута до чипа и микрофона
```

- **Ключевые действия.** Отметить — нажать на всю строку (≥56 pt). «− 2 +» меняет количество, это поле «Сколько». Пункт «Убрать все купленные» работает с «Отменить». Режим «В магазине» включает самый крупный шрифт, экран не гаснет (keep-awake), группы по магазинам видны, рамки и чипы скрыты.
- **Пусто:** листок в клетку «Список пуст. Скажите: «Купить хлеб и молоко»».
- **Строка помощника.** «молоко, хлеб, 2 яйца» — каждое слово через запятую становится строкой. Помощник для этого не нужен: правило работает и офлайн. «Сгруппируй по магазинам» раскладывает строки по группам. «Что купить в аптеке?» даёт ответ плашкой. Сказанное на другой странице («надо купить грунтовку») проговаривается: «Добавил в Покупки [Отменить]».
- **Ручной порядок.** Как сейчас: перетаскивание, «⋯» и «Порядок». Группы тоже переставляются руками. Купленное всегда внизу.
- **Без ИИ / офлайн:** всё, кроме «сгруппируй». Режим «В магазине» должен работать без сети: в магазинах связь часто плохая.
- **200%:** количество уходит под название («×2 · [− +]»). В режиме «В магазине» шрифт ограничен 2× от `title1` и не больше 56 pt.

### 2.5 Документы и КП — картотека

**Зачем.** Найти нужную бумагу по клиенту или типу и вести КП до «Принято».

```
┌──────────────────────────────┐
│ ▤ Документы [Порядок][Настроить]│
│ [  + Новое КП  ]              │ accent 56 (одна на экран)
│ [Все|КП 4|Договоры 2|Чеки 23|…]│ «разделители картотеки» 48
│ ПАПКА · ТОО Арман          3 ›│ группа по клиенту
│ ┌──────────────────────────┐  │
│ │┌───┐ КП № 17              │  │ «лист» 48×64: мини-страница
│ ││≡≡≡│ 1 240 000 ₸ · 3 ноя  │  │ из текста (не фото)
│ │└───┘ Черновик ● Отправлено│  │ полоса статуса:
│ │      ○ Видел ○ Принято  ⋯│  │ точки + слова
│ └──────────────────────────┘  │
│ ┌──────────────────────────┐  │
│ ││PDF│ Договор аренды       │  │ тип словом на «листе»
│ │      Арман · 1 окт      ⋯│  │
│ └──────────────────────────┘  │
│ ПАПКА · Без клиента        24 ›│
│ [+] [Про: Документы ▾ · Сдел…](🎤)│
└──────────────────────────────┘
```

- **Ключевые действия.** «Новое КП» открывает S16. Нажатие на КП ведёт в S17, на документ — в S09. В полосе статуса КП шаг ставит человек нажатием (шторка «Клиент принял?» [Да] [Нет]), и только «Отправлено» ставится само после S18. Разделители — это фильтр по полю «Тип». Папки строятся по полю «Клиент» (`group_key`).
- **Мини-лист** рисуется из текста записи (3 серые строки и тип словом). Фото и скан как превью показываем, только пока жив оригинал (R-34). Когда оригинал удалён, превью удаляется вместе с ним, и лист снова рисуется из текста.
- **Пусто:** пустой ящик картотеки с надписью «Пришлите документ кнопкой «Поделиться» или скажите: «Сделай КП по этому ТЗ»» и одна кнопка «Новое КП».
- **Строка помощника.** «Сделай КП по этому ТЗ» запускает S16. «Найди договор с Арманом» ставит фильтр и подсвечивает запись. «Отметь КП 17 принятым» меняет статус с «Отменить». «Сколько КП принято в ноябре?» — ответ плашкой, считает код.
- **Ручной порядок.** Папки и документы внутри папки можно переставить. Перенести документ в другую папку — значит сменить клиента: шторка «Переложить в папку…».
- **Без ИИ / офлайн:** картотека, фильтры, статусы и перестановка работают. Новое КП требует ИИ и сети. В «Без ИИ» на кнопке написано «Новое КП — нужен помощник», она ведёт в S29.
- **200%:** разделители — выпадающий список «Показать: Все ▾». Мини-лист скрыт, тип стоит словом в начале строки. Полоса статуса — одна строка «Статус: Отправлено ›».

### 2.6 Своя страница — тетрадь

**Зачем.** Своя тема (Ремонт, Дача) и свой порядок записей. Человек сам «расчерчивает» тетрадь.

```
┌──────────────────────────────┐
│ ⌂ Ремонт  ✎ [Порядок][Настроить]│ ✎ — переименовать (как сейчас)
│ [●Список | Чек-лист | Таблица]│ вид сразу на странице, 48
│ ВИД «ТАБЛИЦА»                 │
│ ┌──────┬────────┬─────────┐   │ своё поле = колонка
│ │Что   │Сумма ₸ │Мастер   │   │ шапка закреплена
│ ├──────┼────────┼─────────┤   │
│ │Плитка│ 48 500 │Сергей   │ ⋯ │
│ │Грунт.│  6 200 │—        │ ⋯ │
│ ├──────┼────────┼─────────┤   │
│ │Итого │ 54 700 │         │   │ итог по «Сумма ₸» — код
```

- **Ключевые действия.** Вид переключается прямо на странице (раньше это было только в S38). Нажатие на ячейку открывает правку этого поля в шторке, а не в самой ячейке: так крупнее и понятнее. «+ Колонка» добавляет своё поле с «Отменить». Строка «Итого» появляется, если есть поле «Сумма ₸».
- **Пусто:** чистый разворот тетради с названием страницы и тремя примерами («Запиши: плитка 24 м²», «Добавь колонку — телефон мастера», «Сделай чек-лист»).
- **Строка помощника.** Записать, «добавь колонку телефон мастера», «сделай таблицей», «сколько потратили на ремонт?» (код, источник — эта страница и «Расходы»).
- **Ручной порядок.** Строки таблицы и пункты списка переставляются вручную. Колонки — ↑ ↓ в S38 и голосом.
- **Без ИИ / офлайн:** всё, кроме разбора фраз помощником.
- **200%:** таблица превращается в карточки. Каждая строка — карточка «Плитка · Сумма 48 500 ₸ · Мастер Сергей», поля идут столбиком. Горизонтальной прокрутки нет. Переключатель вида — выпадающий список.

### 2.7 Сегодня — отрывной листок

**Зачем.** За 3 секунды понять, что важно сейчас (S06). Сегодня — системная страница, всегда первая (R-49).

```
┌──────────────────────────────┐
│ ┌────────┐ Вторник       (Н) │ «листок»: число крупно
│ │   10   │ ноябрь            │ type.display 56; аватар 48
│ │ ноября │ Добрый день, Нурлан│
│ └────────┘                    │
│ ┌──────────────────────────┐  │ «Следующее» — одна крупная
│ │ДАЛЬШЕ · через 40 мин      │  │ карточка
│ │🔔 10:00 Позвонить Ерлану  │  │
│ │[Сделано]  [Отложить]      │  │
│ └──────────────────────────┘  │
│ ⚠ Пропущено 08:00 Таблетка    │ красная строка (как сейчас)
│ Ответ готов: «120 000 ₸…» [Открыть]│
│ СЕГОДНЯ                       │ лист дня, как в «Делах»
│ ☐ 18:00 Забрать Алину         │
│ НА СТРАНИЦАХ                  │ ≤2 плитки (Ф-32, решила команда)
│ ┌────────────┐┌────────────┐  │ плитка = итог страницы
│ │⊡ Покупки   ││▣ Расходы   │  │ из screen_summaries
│ │осталось 5  ││сегодня     │  │
│ │          ›││  7 500 ₸ › │  │
│ └────────────┘└────────────┘  │
│ Я СДЕЛАЛ ЗА ВАС · ПРЕДЛОЖЕНИЯ │ как сейчас
│ [+] [Про: Сегодня ▾ · Скажите…](🎤)│
└──────────────────────────────┘
```

- **Ключевые действия.** «Дальше» показывает ближайшее дело или будильник с кнопками [Сделано] [Отложить на 10 минут] (те же слова, что в S14, R-11). Плитка открывает свою страницу. Остальные секции и порядок секций (`DEFAULT_SECTIONS`) остаются как на неделе 9.
- **Пусто:** листок с числом и надписью «Сегодня свободно. Скажите: «Напомни в пятницу оплатить свет»» (первая подсказка, R-37).
- **Строка помощника.** Любая фраза: помощник сам понимает, куда её положить, и проговаривает это («Поставил в Дела…»). Вопросы идут по всем страницам.
- **Плитки (Ф-32, решение команды).** Не больше 2. Плитка показывается, только если на странице есть что-то на сегодня: «Покупки: осталось 5»; «Расходы: сегодня 7 500 ₸», если траты были за последние 7 дней; «Документы: КП ждёт ответа 2». Пусто — плитки нет. Какие именно, выбирает код по этому правилу, без ИИ. Человек может закрепить или скрыть плитку («⋯ Ещё → Показывать на Сегодня / Не показывать» у страницы в S34 или на самой плитке). Закреплённое человеком главнее правила. У новых пользователей первые 7 дней плиток нет: «Сегодня» должна оставаться простой.
- **Ручной порядок.** Порядок закреплённых плиток задаёт человек. Секции «Сегодня» адаптивные (1-product §6.9). Ручной порядок секций не предлагаю: это лишняя настройка.
- **Без ИИ / офлайн:** всё собирается из того, что лежит на телефоне (так уже сделано на неделе 9). Предложения не показываются.
- **200%:** листок с числом уходит в одну строку «Вторник, 10 ноября». Плитки идут в 1 колонку, их не больше 2. «Дальше» остаётся первой карточкой.

### 2.8 Помощник меняет вид страниц (Ф-31)

**Решение основателя:** «помощник запросто может, в целом было бы хорошо, если помощник мог видоизменять все экраны по возможности, по необходимости». Ниже — как это укладывается в обязательные правила.

**Что считается «видом».** Режим и раскладка (ряды / доска, список / чек-лист / таблица, «Простой список», «В магазине»), цвета стикеров, «приколоть», видимые поля и их порядок, свои поля, сортировка, группировка, фильтр, период «Расходов», порядок категорий-чипов, плитки «Сегодня», название и иконка страницы. Записи, суммы и даты к виду не относятся: их правка идёт по прежним правилам (R-31, R-36).

**Три правила, которые не обходятся:**
1. **Только по вашей просьбе.** Вид меняется, если об этом сказал человек в строке помощника (правило намерения R-56). Текст внутри записей, документов, выписок, писем и «Поделиться» никогда не запускает изменение вида: это `untrusted_data`, и инструмент просто не вызывается. Сам по себе, без просьбы, помощник может только **предложить** («Покупок 30 — показать по магазинам? [Да] [Не сейчас]»): это подсказка в лимитах R-35, и без «Да» ничего не меняется.
2. **Всегда видно и отменяемо.** После изменения в строке появляется итог «Сделал Покупки по магазинам [Что изменилось] [Отменить]». В «Что изменилось» каждая настройка — отдельной строкой с «Вернуть»: «Вид: Ряды → Доска», «Цвет: 6 стикеров про ремонт → зелёный». Копия хранится в «Что я сделал» 30 дней.
3. **Ваше — ваше.** У каждой настройки записано, кто её поставил (`set_by: user | agent | template`). То, что человек поставил руками, помощник меняет только после «Да».

**Что можно сразу и что требует «Да»:**

| Что | Когда просят | Пример |
|---|---|---|
| Сменить режим / раскладку из разрешённых для шаблона | **сразу**, с «Отменить» | «покажи таблицей», «включи доску», «сделай простым списком» |
| Сортировка, группировка, фильтр, период | **сразу** | «сгруппируй по магазинам», «покажи за неделю» |
| Показать / скрыть поле (кроме ★), порядок полей, добавить своё поле (≤5) | **сразу** (как R-51) | «добавь поле телефон мастера», «спрячь источник» |
| Цвет стикеров, у которых цвет не ставил человек; «приколоть» названную запись | **сразу** | «раскрась по темам», «приколи код домофона» |
| Название и иконка страницы | **сразу** | «назови страницу Дача» |
| Всё, что человек поставил руками: его цвета, места на доске, ручной порядок, порядок категорий, закреплённые плитки | **одно «Да» с числом** | «Вы сами покрасили 4 стикера. Перекрасить и их? [Да] [Оставить мои]» |
| Изменение больше 150 записей, убрать своё поле, «Вернуть как было» | **одно «Да» с числом** (S25) | «Убрать поле «Мастер»? Значения сохранятся» |
| Изменение на другой странице, не на текущей | **сразу**, но проговаривается | «Сделал Покупки по магазинам [Открыть] [Отменить]» |
| Скрыть поле ★, придумать новый вид не из списка, менять формулы итогов, менять вид без просьбы | **никогда** | — |

**Привычка.** Если человек сказал «всегда раскрашивай новые заметки по теме», это становится правилом в S30 «Что я для вас настроил» (F-29), которое видно и можно убрать. Без такого правила новые стикеры белые.

**Связь с неделей 11 (R-51, «Правка шаблона»).** Это тот же набор настроек, что в S38, просто ими управляют голосом. Неделя 11 делает одну функцию `set_view`: белый список настроек по шаблону, проверка ★, `set_by`, `confirm_manual`, action с `inverse`. Эту функцию вызывают и S38 (руками), и помощник (инструмент). R-51 расширяется: в список настраиваемого добавляются режим, цвета и плитки. Формулы, связи и свои итоги остаются «после MVP».

## 3. Что общее у всех экранов

Это держит приложение единым и даёт переиспользовать код. Правило: **по краям экрана всё одинаковое, в середине — инструмент**.

| Элемент | Как сейчас | Что меняется |
|---|---|---|
| **Рамка страницы** `PageFrame` | шапка внутри `page/[id].tsx` | выделяется в общий компонент: иконка + название + «Порядок» + «Настроить» + «Найти на странице» + слот для инструмента + плашки «Пока вас не было…». У «Сегодня» нет «Порядок» и «Найти» |

## 5. Доступность

- **Каждый инструмент читается как список.** Для VoiceOver и TalkBack стикер, строка ленты, ячейка ежедневника и документ звучат одной фразой: «Стикер, жёлтый, приколот. Код домофона 4512. Сегодня»; «Трата. Пять тысяч тенге. Бензин. Транспорт. Сегодня»; «Десять ноль-ноль. Будильник. Позвонить Ерлану. Не сделано». Порядок фокуса совпадает с порядком `position`.
- **Цвет стикера не несёт смысла.** Если человек сам делит заметки по цвету, есть фильтр «Показать: Жёлтые» с подписью словами, а название цвета озвучивается.
- **Клавиши калькулятора:** 64 pt, расстояние ≥8 pt, у каждой подпись («плюс», «стереть», «записать»). Сумма озвучивается словами по мере ввода (live region polite). Работает внешняя клавиатура: цифры, Enter — «Записать».
- **Табло:** при «Увеличить контраст» рамка становится `lineStrong`. Число не обрезается: если не помещается даже при 1,6×, оно переносится на две строки по разрядам.
- **Ежедневник:** линия «сейчас» — это ещё и текст «Сейчас 11:20», не только цвет. Время у дела всегда цифрами, без «утром».
- **Режим «В магазине»:** строка ≥72 pt, нажимается целиком; «Выйти» — кнопка со словом. Экран не гаснет, пока открыт режим, а через 30 минут без касаний спрашивает «Ещё в магазине?».
- **Таблица:** при ≥150% только карточки. Горизонтальной прокрутки нет нигде.
- **Доска:** у каждого стикера пользовательские действия «Выше / Ниже / Левее / Правее / Наверх доски». При ≥150% и при включённом чтении с экрана доска показывается рядами (места сохраняются).
- **Изменение вида помощником:** итог объявляется (live region polite), например «Вид изменён: по магазинам. Отменить». Фокус остаётся на той же записи, если она осталась на экране. Ничего не перестраивается, пока человек держит палец на списке (R-54).
- **Без скрытых жестов:** перетаскивание стикера, свайп по строке ленты и долгое нажатие только дублируют «⋯ Ещё». Пользовательские действия для чтения с экрана — те же, что на неделе 7.
- **Движение:** у стикеров нет поворотов и «прилипания» с отскоком; при «Меньше движения» вместо анимации затухание. Пересчёт табло при Reduce Motion показывает итог сразу и подпись «было 213 050».
- **Скриншот-тесты:** 7 инструментов × 100/150/200% × RU/KK × светлая/тёмная, на 360×640 и iPhone SE. Это добавляется к чек-листу §8 в 2-design.
- **Тест на 5 людях 50–70:** к задачам добавляются «запишите трату 1 200 + 350 на продукты», «сделайте заметку жёлтой и приколите», «отметьте покупки в режиме В магазине», «найдите договор в папке клиента». Кроме того, надо проверить, понимают ли люди, что это одно приложение: 5-секундный тест на двух разных страницах.

## 7. Риски, кратко

1. **Семь разных экранов — один язык.** Если тест на 5 людях покажет, что человек «теряется» на новой странице, первым делом выравниваем кнопки рамки, а не убираем инструменты.
2. **Сетка стикеров на 1 000 записей.** Нужен виртуализированный список по 2 колонки (FlashList), а перетаскивание в сетке сложнее, чем в списке. Проверяем на Redmi на неделе 11а; доску — на неделе 16а.
3. **Клавиши калькулятора против строки помощника.** Два способа ввести трату на одном экране. Строка — для «скажите», клавиши — для «набрать руками». Подписываем так: над клавишами «Набрать сумму», в строке «Или скажите».
4. **Страница «вдруг другая».** Помощник меняет вид только по просьбе и всегда с «Отменить» (2.8). Если на бете отмены изменений вида больше 10% (`page_action_undone` по `set_view`), сужаем то, что можно «сразу».
