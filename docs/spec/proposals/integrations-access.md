# Доступ к другим приложениям, чатам ИИ и фото

Ответы команды основателю (2026-11-12 … 2026-11-15). Основатель согласен с рекомендациями; в план не поставлено — решение о сроках отдельно.

## 1. Переписки и приложения (2026-11-12)

Целиком «подключить всё» нельзя ни на iPhone, ни на Android: iPhone не даёт одному приложению читать другие, Google Play запрещает или сильно ограничивает такие разрешения. Работает только то, что человек выбирает сам.

| Источник | Вердикт | Работа (оценка) |
|---|---|---|
| «Поделиться» из любого приложения | уже есть | — |
| Выгрузка Telegram (файл) | уже есть | — |
| WhatsApp «Экспорт чата» (файл) | можно | 3–5 дней |
| Календарь и контакты телефона (с разрешения) | можно | 3–5 дней |
| Telegram-бот для пересылки | позже | ~1 неделя |
| Вход в Telegram по коду | позже (Ф-43) | 2–4 недели, риск блокировки |
| Gmail напрямую | позже, платно: ежегодная проверка CASA ≈ $500–4 500 | недели |
| Чтение уведомлений (только Android) | позже, по запросу пользователей | 1–2 недели + проверка Google |
| SMS, «чтение экрана», личные сообщения Instagram/TikTok, WhatsApp Business для помощника | нельзя | — |

Закон 94-V: в переписках есть другие люди, они согласия не давали — берём только выбранное человеком, оригиналы долго не храним, кнопка «удалить импорт», в политике — «вы отвечаете за то, что пересылаете».

## 2. Чаты ИИ: ChatGPT, Claude, Gemini (2026-11-15)

| Способ | Вердикт |
|---|---|
| Выгрузка данных (ChatGPT: Настройки → Управление данными → Экспорт; Claude — экспорт в настройках; Gemini — Google Takeout) → файл нам → разбор как выгрузка Telegram | можно, ≈ 3–5 дней на первый, остальные — на той же основе |
| Публичная ссылка на один чат («Поделиться») → через «Поделиться» к нам | можно |
| Подключение к аккаунту (OAuth к чатам) | нет такого API у провайдеров |
| Вход по логину и паролю человека | нельзя (правила провайдера, безопасность) |
| «Память» ChatGPT | только скопировать вручную |

Рекомендация: один импорт «выгрузка чатов ИИ» для всех трёх, человек сам выбирает файл. Перепроверить форматы выгрузки на актуальность перед разработкой.

## 3. Фото и «почистить галерею» (2026-11-15)

Технически можно: доступ к галерее с разрешения человека; удаление — только с системным подтверждением телефона (молча удалить нельзя), удалённое 30 дней в корзине телефона.

Что можно находить: одинаковые и почти одинаковые фото (серии), размытые и тёмные, скриншоты и фото чеков/экранов, большие старые видео.

Рекомендация (основатель согласен): разбирать **на телефоне**, без отправки фото в облачный ИИ — бесплатно, без интернета, без трансграничной передачи самых чувствительных данных.

Риск: Google Play с 2024 г. пускает к полной галерее только приложения, для которых это главная функция — при проверке нужно обоснование и демонстрация; iOS проще. Оценка ≈ 2–3 недели. Перед разработкой перепроверить актуальные правила Google Play и инструменты (expo-media-library, ML Kit / Vision).
