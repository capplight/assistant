# UX/UI-аудит — сокращённый объём

2026-11-13 · аудит по коду `mobile/src`, экран 360×800 dp (Samsung A23), обычный шрифт · учтены решения основателя Ф-33…Ф-45 (`docs/spec/FOUNDER-DECISIONS.md`).
Что остаётся на виду: приветствие → «Сегодня», «Заметки» (только «Ряды»), «Дела», «Ещё» (6 строк), «Настроить страницу» (название, значок, вид). «Покупки», «Расходы» и «Документы» появляются по первой записи. Остальное спрятано.

## 1. P0 — что ломает экран сейчас

1. **Низ экрана занимает до половины высоты.** Строка помощника ≈117 dp вместо 64 по спецификации: чип «Про: …» (48) стоит над полем (48), `components/AssistantLine.tsx:334-341`. Ниже вкладки 65–87 dp и системная панель 48 dp. Плашка ответа добавляет 150–220 dp (`AnswerBanner.tsx:134-149`, две кнопки по 56), полоса «Отменить» — ещё 64. В итоге под контент остаётся 300–550 dp из 800.
   → Строка — одна капсула ≈56 dp: «+» и микрофон внутри, «Про: Заметки» в плейсхолдере. Ответ и «Отменить» — компактный тост в одну строку с одной кнопкой и крестиком.
2. **Шапка каждой страницы ≈166 dp.** Кнопки «Порядок» и «Настроить» переносятся на вторую строку, ниже всегда стоит поле «Найти» 56 dp (`page/PageFrame.tsx:69-117`).
   → Одна строка: заголовок + 🔍 + ⋯. В ⋯ — «Порядок», «Настроить». Поиск открывается по 🔍.
3. **«Сегодня» не показывает главное.** На первом экране — жёлтая плашка риска будильников (≈170 dp, `ReminderCards.tsx:21-46`), «листок»-календарь (≈110) и «Дальше» с кнопками по 56 dp (≈215). До списка дня не долистать. Ниже идут 6 прописных меток секций и outline-кнопка «Новое напоминание».
   → Три блока: «Дальше» (одна главная кнопка, «Отложить» второстепенно) · «Сегодня» единым списком · одна подсказка (только неделю, Ф-42). Риск будильника — узкой строкой и только когда будильник уже поставлен.
4. **Заметки: стикер ≈154 dp шириной.** При 18 sp это ≈12 знаков в строке. Под текстом 2–3 серые мета-строки и синяя «⋯» 48 dp, у каждого стикера рамка и «загнутый уголок» (`page/StickersView.tsx:214-354`). Переключатель «Ряды | Доска» занимает 64 dp (`:154`), хотя доска выключена (Ф-38).
   → Убрать переключатель. Стикер: текст 15–17, одна мета-строка, без рамки, «⋯» тихим серым значком.
5. **Дела: строка в 4 уровня.** Квадрат 40 + время 64 + «⋯» 48 оставляют на название ≈150 dp (`page/PlannerView.tsx:270-374`). Сегменты «Сегодня / Скоро / Пропущено» выделены рамками 1 и 3 px (`ReminderLists.tsx:248-271`). Отмеченное дело заливается серым `ink2` (`TaskRow.tsx:87-88`).
   → Нативный сегментный переключатель, строка в 2 уровня, галочка фирменного или зелёного цвета.
6. **«Ещё»: 17 строк без групп и с двумя заглушками** (`app/(main)/more.tsx:105-133`). Ф-41 уже это решает. Шесть строк — одной сгруппированной карточкой с иконками, «Удалить аккаунт» — внутри «Настроек».
7. **Экраны без «Назад».** У «Поиска» и «Всех записей» нет кнопки назад, а вкладка при этом подсвечивает «Сегодня» (`BottomTabs.tsx:37`).
8. **Приветствие выглядит как прототип.** Вместо иллюстрации — пустые прямоугольники, вместо выбора — текстовые глифы «● ☑ ☐» (`(onboarding)/welcome.tsx:79-94, 124-127, 176-178`). Нужно: одна картинка в фирменном цвете, язык, «Начать», строка о Политике (Ф-34).

## 2. Дизайн-система

- **Размеры (Ф-45).** Сейчас базовый текст 18, вторичный 16, кнопка **20 — крупнее текста**, метки секций 15 прописными, все кнопки по 56 (`theme/typography.ts:30-48`, `Button.tsx:46`). Новая шкала по образцу iOS: заголовок экрана 28–34 · заголовок 20–22 · основной 16–17 · кнопка = основному · вторичный 13–15 · метки без прописных. Видимая высота кнопки 44–50, зона нажатия ≥48 через `hitSlop`. Крупный шрифт — из системы, до 200 %. Поля экрана: 16 при ≤375 dp, 20 на больших экранах.
- **Цвет.** Один синий #2F4BD8 окрашивает и главные кнопки, и обводки, и ссылки, и «⋯», и стрелки. Фон #F6F3EC и карточки #FFFDF8 почти не отличаются (≈1.04:1), границы держатся на линии 1.2:1. Серый `ink2` стоит у 180 строк. Нужны роли: **brand** (только залитые главные элементы) · **brandTint** (выбранное, чипы, иконки «Ещё») · **iconSecondary** серый для «⋯» и шевронов · статусы success / warning / danger с тинтами · `fill` вместо рамок у полей и переключателей. Сам фирменный цвет выберет основатель из вариантов старшего дизайнера.
- **Поверхности.** В коде 67 рамок по 1 px, 30 рамок по 2 px и 133 кнопки с синей обводкой. Нужно: белые карточки без рамок на чуть более тёмном фоне, разделители с отступом, тени только у плавающих элементов. Меню в шторках — строками, а не столбиком outline-кнопок.
- **Компоненты-дубли.** Сделать по одному компоненту вместо копий:
  - `Sheet` + `ActionList` — сейчас ≈15 своих шторок, у одной нет скругления (`TodaySheet.tsx:256`);
  - `SegmentedControl` — сейчас 4 реализации;
  - `Header` — сейчас 4 вида «Назад»;
  - `Checkbox` — сейчас 4 вида: 32, 40, 44 и глифы;
  - `ListRow`, `IconButton` («⋯» скопирована 5 раз) и `Card`.
- **Мелочи.** Иконки 8 размеров (16–40) — оставить 3: 20, 24, 28, все с обводкой 1.75. Скругления: литералы 2/4/5/6/8 заменить на шкалу 6 / 10 / 14 / 20. Нажатие сейчас только `opacity 0.85`. Токены `motion.*` почти не используются.
- **Адаптивность.** Вёрстка ветвится только по крупному шрифту, по ширине — нет. Нужны три ширины: <360, 360–599, ≥600. На планшете низ экрана ограничить 600 dp, как контент.

## 3. Навигация (рекомендация, решает основатель)

Страниц по умолчанию теперь 3 (Ф-35), поэтому:

- **Вкладки: «Сегодня» · «Заметки» · «Дела» · «Ещё»** — 4 штуки, подписи в одну строку, иконка 24, активная — тонированная «пилюля» бренда. Новые страницы («Покупки», «Расходы», «Документы») появляются по первой записи. Если страниц больше трёх, они попадают в начало «Ещё». Вкладок никогда не больше 4.
- **Помощник — одна капсула над вкладками**, одинаковая везде. При прокрутке вниз она сворачивается до кнопки-микрофона.
- **Всё остальное — экраны стека с общим `Header` «‹ Назад»:** поиск (по 🔍 в шапке), запись, переписка, настройки. Вкладка остаётся подсвеченной по месту, откуда пришли.
- **Правило каждого экрана:** одна залитая кнопка. Действия над записью — в её карточке или в ⋯. Настройки вида — в ⋯ страницы.

**Порядок работ:** сначала шкала и цвет-роли, затем общие компоненты. После этого низ и шапка (п. 1–2), затем «Сегодня», «Заметки», «Дела».
