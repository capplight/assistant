# Структура приложения v2: помощник сам раскладывает записи

2026-11-13 · старший продуктовый дизайнер.

**Основание.**
- Ф-47: «Про: …» убрано, помощник сам решает, куда положить запись и где искать.
- Посмотрел код: `mobile/src/app`, `components/ui`, `store/features.ts`.

Макеты в `ia-v2.html`, тема «Мята»: А1 — 4 экрана, А2 — 5, А3 — 4.

**Главный вывод.** Раньше страницы были местом, *куда пишут*. Теперь пишут в одну строку, а страницы стали местом, *где смотрят*. Отсюда три следствия:
- навигацию строим вокруг «посмотреть и проверить»;
- у каждого действия помощника должен быть видимый след с отменой;
- отдельный «Поиск» не нужен.

## 1. Как устроено сейчас

```
Приветствие (+строка о Политике) → Сегодня          [start / gallery / phrase / consent — старый путь за флагами]
Низ каждого экрана: плашка ответа / «Отменить» · строка помощника · вкладки
Вкладки: Сегодня · Заметки · Дела · Ещё
├ Сегодня: ожидающий ответ · риск будильника · «Дальше» · «На сегодня» · предложения / подсказка
├ Страница (Заметки, Дела, Покупки*, Расходы*, Документы*, свои): ⋯ = Порядок · Переименовать · Найти · Настроить
│   └ запись, стопка                                                               (* — после первой записи)
├ Поиск (🔍 в шапке)
└ Ещё: [вход / согласие] · профиль → Настройки · Ваши страницы · Новая страница · Мои страницы · Что я сделал · Принести заметки · Настройки
    └ Настройки: телефон | Мои данные · Все записи · Повторы · Корзина | Переписка · Привычки · Будильники | Язык · Тема | Политика · Условия · Согласия · Поддержка · Версия | Удалить аккаунт
Стек: КП (новый, редактор, цены, отправка, версии) · Реквизиты · Прайс · Черновик · Новое напоминание · Будильник · Привычки · Переписка · Что я сделал · …
```

**Где неудобно.**
- «Что я сделал» и «Переписка» — два журнала одного и того же, причём «Переписка» спрятана в Настройках, в трёх нажатиях.
- Поиск есть в трёх местах: строка-вопрос, 🔍 в шапке и «Найти» в ⋯ страницы.
- Новые страницы теряются в «Ещё». Отцу до КП 3 нажатия.
- Вкладки «Заметки» и «Дела» нужны основателю и жене, а отцу — нет.

## 2. Три варианта

| | **А1 · 4 вкладки, вычищенные** | **А2 · Сегодня · Страницы · История** (рекомендую) | **А3 · Главная = помощник + лента** |
|---|---|---|---|
| Суть | Каркас как сейчас. Ответ — карточка прямо над строкой. «Ещё»: страницы + 4 пункта | 3 вкладки. «Страницы» — карточки с цифрами и превью, вкладка помнит последнюю открытую. «История» — что сказал → что сделал, с «Отменить». Профиль — аватар на «Сегодня» | Одна главная: большой вопрос, ниже «Впереди» и «Только что». Страницы — чипы. Вкладок нет |
| Покупки, Расходы, Документы | в «Ещё → Ваши страницы» (1–2 нажатия) | карточка на «Страницах» появляется после первой записи (1 нажатие) | чип на главной |
| Поиск | вопрос в строке + 🔍 на странице | вопрос в строке; 🔍 на «Страницах» = «Все записи» | только вопрос в строке |
| Переписка / что сделал | «Ещё → История» | **вкладка «История»** | «Только что» на главной + аватар |
| Основатель (сотни заметок) | + заметки в 1 нажатие | ≈ «Страницы» помнят «Заметки», тоже 1 нажатие; «История» нужна при повторах | − лента шумит, заметки в 2 нажатиях |
| Жена (будильники) | + «Дела» — вкладка | + «Сегодня» = всё про день; голос → карточка подтверждения | + «Впереди» сверху |
| Отец (КП) | − Документы в 2 нажатиях | + карточка «Документы · КП № 14» видна сразу | ≈ чип |
| Пожилые | + привычно | + 3 крупные вкладки, «где моё?» — в «Истории» | − нет постоянного «места», есть риск потеряться |
| Риски | «Ещё» снова разрастается, страницы неравноправны | меняет Ф-35 (вкладки = страницы) и Ф-41 («Ещё» 6 строк) — **решает основатель** | самая сложная, лента требует хорошего ранжирования |
| Цена работ | малая | средняя: TabBar, экран «Страницы», объединение `chat` и `did` | большая |

**Рекомендация: А2.** Почему:
- она прямо отражает новую модель: пишу в строку → смотрю на «Страницах» → проверяю и отменяю в «Истории»;
- одинаково работает для всех трёх людей: у каждого свои страницы, и не надо решать, какие из них — вкладки;
- для пожилых даёт ответ на главный страх «куда делось?».

Если основатель не хочет трогать Ф-35 и Ф-41, — **А1**: в ней всё из раздела 3, кроме вкладок.

## 3. Что убрать, слить или перенести (для А2; пометка «А1» — подходит и для А1)

| Что | Решение | Почему |
|---|---|---|
| «Про: …» в строке | удалить (Ф-47); открытая страница остаётся скрытым контекстом для слов «это» и «здесь» | человек не выбирает место |
| «Переписка» (`chat`) + «Что я сделал» (`did`) + плашка ответа | **один журнал «История»**: «Всё · Изменения · Вопросы», у каждого изменения есть «Отменить» (А1) | один след вместо трёх; из Настроек уходит |
| Экран «Поиск», «Найти» в ⋯ страницы, всегдашняя 🔍 | вопрос в строке отвечает **значением** («4512»), а не списком. 🔍 оставить одну — на «Страницах»: «Все записи · искать по словам». «Найти» в ⋯ убрать (А1) | три поиска → один, и ответ без лишнего перехода |
| «Ваши страницы», «Новая страница», «Мои страницы», `pages-gallery` | вкладка «Страницы»: карточки, «+ Страница», порядок перетаскиванием | 4 входа → 1 |
| «Ещё» как вкладка | аватар на «Сегодня» → Профиль и настройки (там же «Принести заметки») | лишняя вкладка с 4 пунктами |
| «Все записи» и «Повторы» в Настройках | «Все записи» — внизу «Страниц». «Повторы» — одна карточка на «Сегодня», когда они найдены (А1) | данные — не настройки |
| ⋯ страницы: Порядок · Переименовать · Настроить | один пункт «Настроить страницу»: название, значок, вид, порядок (А1) | Ф-40 |
| Риск будильника на «Сегодня» | одна строка и только после первого будильника (А1) | аудит, п. 3 |
| «Привычки» | за флаг, пока не попросят; повторяющиеся дела живут в «Делах» | не входит в «7 идеальных вещей» |
| `reminder-new` (форма) | шторка-подтверждение после голоса: «Готово · Изменить время»; форма — только из «Изменить» (А1) | 7–9 нажатий → 2 |
| КП: `kp/prices` + `price-list` + `company` | один экран «Данные для КП» (реквизиты + прайс). `kp/send` — шторка, версии — в ⋯ КП (А1) | 6 экранов → 3 |
| Старый онбординг (`start`, `gallery`, `phrase`, `consent`) | оставить за флагами, в навигации их нет | Ф-34 |

## 5. Следующие шаги
1. Основатель выбирает А1 или А2 (А2 меняет Ф-35 и Ф-41).
2. Независимо от выбора и сразу:
   - объединить «Переписку» и «Что я сделал» в «Историю»;
   - ответ значением вместо списка;
   - шторка подтверждения для голоса;
   - «Настроить страницу» одним пунктом;
   - «Данные для КП».
3. Для А2:
   - TabBar на 3 вкладки;
   - экран «Страницы» (сетка `Card`, 2 колонки, на ширине ≥600 — 3);
   - аватар в `Header`;
