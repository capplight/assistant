# Референсы: Расходы · КП · Поиск · Ещё

2026-11-13. Только сильные референсы и то, что в них хорошо. Объём урезан по Ф-33…Ф-45: размеры как в iOS/Android, текст 16–17.

## Расходы
Вкладка показывается только после первой траты (Ф-36). Выписок и QR-чеков в бете нет (Ф-37).

- **[Copilot Money](https://apps.apple.com/us/app/id1447330651)** — финалист Apple Design Award 2024. Одна крупная сумма за месяц без рамки, под ней тонкая линия трат с пунктиром прошлого месяца. У каждой категории свой цвет и эмодзи.
- **[Monarch](https://www.monarch.com/monarch-brand-refresh)** — спокойная светлая палитра. Карточки отделены от фона тоном, а не линиями.
- **[Monefy](https://screensdesign.com/showcase/monefy-money-tracker)** — трата добавляется за два касания: категория, потом сумма. Цвет категории одинаков везде.
- **[YNAB: ввод трат](https://www.ynab.com/whats-new/the-clearest-way-to-enter-transactions)** — сначала большая сумма и цифровая клавиатура, всё остальное вторично.

## Документы / КП
- **[Invoice Simple](https://invoicesimple.com/features/create-estimates-invoices)** — смета набирается построчно: позиция, «кол-во × цена», внизу итог. Готовую смету можно превратить в счёт одним касанием.
- **[Zoho Invoice](https://apps.apple.com/us/app/id413017364)** — в списке у каждого документа статус словом и цветом: черновик, отправлено, принято. Есть [отправка в WhatsApp](https://help.zoho.com/portal/en/community/topic/coming-soon-in-zoho-invoice-send-invoices-directly-via-whatsapp).
- **[Joist](https://www.joist.com/features/estimates/)** — сделан для подрядчиков. Перед отправкой показывает предпросмотр A4, отправить можно прямо с объекта.

## Поиск
- **[Apple HIG: Search fields](https://developer.apple.com/design/human-interface-guidelines/search-fields)** и **[Material 3: Search](https://m3.material.io/components/search/overview)** — платформенная основа: под полем фильтры-чипы, результаты сгруппированы по источнику, совпадение подсвечено.
- **[Perplexity](https://www.perplexity.ai)** — сначала короткий ответ, под ним пронумерованные источники. Для нас это ответ из записей со ссылками на сами записи.
- **[Things 3](https://culturedcode.com/things/)** — Quick Find: одно поле ищет везде, а пустой экран показывает недавнее.

## Ещё / Настройки
6 строк, служебное уходит в «Настройки» (Ф-41).

- **[Apple HIG: Lists and tables](https://developer.apple.com/design/human-interface-guidelines/lists-and-tables)** и **[Telegram](https://telegram.org/apps)** — карточка профиля, одна-две группы строк, у каждой строки цветной квадратный значок. Этот паттерн пользователь знает по своему телефону.
- **[Material 3: Lists](https://m3.material.io/components/lists/overview)** — тот же список в нормах Android.

## Фирменный цвет (Ф-45)
У всех референсов выше один акцентный цвет, и он используется только для действий. Цвета категорий и статусов задаются отдельно. Фирменный цвет должен работать на светлом и тёмном фоне. Варианты предложит старший продуктовый дизайнер.
