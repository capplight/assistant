# Насмотренность: «Сегодня», Помощник, Первый запуск

*Ноябрь 2026. Короткий список сильных референсов с учётом решений Ф-33…Ф-45. Мокапы из `.html` основатель не принял: это просто черновики, на них не опираемся.*

Рамки, заданные решениями:
- первый запуск: приветствие → «Сегодня», строка о политике конфиденциальности, отдельного экрана согласия нет (Ф-34);
- на «Сегодня» одна подсказка, только в первую неделю (Ф-42);
- размеры как в iOS/Android, текст 16–17 (Ф-45);
- нужен фирменный цвет.

## «Сегодня»

- **[Things 3](https://apps.apple.com/app/id904237743).** Спокойный список без рамок, один акцент, много воздуха. Цвет появляется только там, где есть смысл (просрочено, сегодня).
- **[Apple Напоминания](https://apps.apple.com/app/id1108187841).** Плитки с крупным числом («Сегодня 3») читаются без чтения. Каждый список отмечен своим цветом.
- **[Structured](https://apps.apple.com/app/id1499198946).** День как одна лента по времени, цветные значки дел. «Что дальше» видно сразу.
- **[Tiimo](https://apps.apple.com/app/id1480220328)** (iPhone App of the Year 2025). Мягкие цвета и крупные карточки, дружелюбно без детскости.
- **[Apple Journal](https://apps.apple.com/app/id6447391597).** Крупная дата и типографика вместо украшений. Выглядит «дорого» за счёт шрифта и пустоты.

## Помощник: строка ввода, «Переписка», плашка ответа

- **[ChatGPT](https://apps.apple.com/app/id6448311069) / [Claude](https://apps.apple.com/app/id6473753684).**
  - Строка ввода — одна капсула, «+» и микрофон внутри неё.
  - Ответ идёт без пузыря, вопрос — в тонированном пузыре.
  - Пример для нашей строки и «Переписки».
- **[Telegram](https://apps.apple.com/app/id686449807).** Пузыри и вложения-карточки, которые все уже умеют читать. Ориентир для «Переписки», если нужна привычность.
- **[Perplexity](https://apps.apple.com/app/id1668000334).** Источники ответа — маленькими чипами под текстом. Так можно показать «нашёл в Документах».
- **[Google Gemini (Gemini Live)](https://apps.apple.com/app/id6477489729).** Голосовой режим: крупная расшифровка речи и живая анимация «слушаю». Ориентир для экрана записи голоса.
- **[Arc Search](https://apps.apple.com/app/id6472513080).** Ответ собирается в аккуратную карточку, а не в стену текста. Ориентир для короткой плашки ответа.

## Первый запуск: приветствие и разрешения по месту

- **[Apple HIG: Onboarding](https://developer.apple.com/design/human-interface-guidelines/onboarding).**
  - Канон: один экран, 2–3 обещания с иконками, одна кнопка.
  - Разрешения спрашивать в момент, когда они нужны.
- **[Duolingo](https://apps.apple.com/app/id570060128).** Показывает продукт в деле до регистрации, а не объясняет его. У нас аналог — 2–3 примера фраз на приветствии.
- **[Headspace](https://apps.apple.com/app/id493145008).** Тёплый экран перед системным запросом уведомлений: объясняет, зачем они нужны. Шаблон для «Разрешить напоминания» при первом будильнике.
- **[Signal](https://apps.apple.com/app/signal-private-messenger/id874139669).** Приватность одной строкой на старте, без юридической простыни. Пример для строки «Нажимая «Начать», вы принимаете Политику…».
