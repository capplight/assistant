# Вычитка казахских строк

Файл `kk-review.csv` — все строки приложения на казахском рядом с русскими. Открывается в Excel или Google Таблицах.

Что делать:

1. Читайте столбцы `ru` (русский) и `kk` (черновик на казахском). `where` — где строка в приложении, `length` — длина и
   сколько места на экране при крупном шрифте, `checks` — что нашла автоматическая проверка, `comment` — вопросы.
2. Если казахский текст нужно исправить, напишите правильный вариант в столбец **`kk_new`**. Если всё верно —
   оставьте `kk_new` пустым.
3. Не меняйте то, что в фигурных скобках: `{{n}}`, `{{page}}` и т. п. — туда приложение подставит число или название.
4. Строки с пометкой «форма one / other»: `one` — для 1, 21, 31…, `other` — для остальных чисел.
5. Вопросы и сомнения пишите в столбец `comment`.
6. Сохраните как **«CSV UTF-8»** (Excel: Файл → Сохранить как → «CSV UTF-8») или в Google Таблицах: Файл → Скачать → CSV.

Апостроф `'` в начале некоторых ячеек — служебный, его можно не трогать.
